Create `docs/decisions/NNNN-short-title.md` when a security, data-model, API,
or evaluation choice has long-lived consequences. Record context, decision,
alternatives, consequences, status, date, and issue/PR links. Create
`docs/plans/<issue>-short-title.md` only for work that spans multiple sessions.

Keep claims evidence-based. Synthetic fixtures may be committed; real session
logs, transcripts, tokens, user paths, and secrets may not. Document changes to
detection semantics alongside scorer and API changes.
