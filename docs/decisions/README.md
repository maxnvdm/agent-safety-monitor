# Architecture decision records

Create `NNNN-short-title.md` when a decision has meaningful alternatives and
long-lived consequences.

Use this structure:

```markdown
# NNNN: Decision title
- Status: proposed | accepted | superseded
- Date: YYYY-MM-DD
- Issue: URL
- Pull request: URL

## Context
## Decision
## Alternatives considered
## Consequences
## Superseded by
```

Keep ADRs concise and factual. Do not rewrite accepted history; add a new ADR
and mark the old one superseded.
